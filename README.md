# 静风效应 · 桥梁抗风交互课堂

**公开课堂：[打开交互课堂](https://syzhaoln-stack.github.io/bridge-static-wind-classroom/#torsion)**

适合电脑和手机，可直接调节风速、拖动桥面和观察力矩关系。

## 四个模块

1. 平均风速与桥梁坐标。
2. 截面与阻力、升力、力矩。
3. 高度与平均风荷载。
4. 扭转平衡与静力发散：三维桥面、两力矩曲面、平衡交线投影及局部稳定条件推导。

## 两个扭转实验

- 调风速，观察桥面逐步停在新的稳定平衡角。绿色虚线截面标出此风速的平衡位置。
- 手动扭偏再松手：临界前回到当前风速的平衡位置；略越临界后，固定风速下仍持续偏转。

默认跨中截面近景，上下拖动扭偏桥面，松手自动观察；也可切换为旋转视角。滚轮或双指缩放。公式、曲面、投影与平衡目标使用同一组参数。

## 离线使用与更新

下载 `index.html` 后直接用浏览器打开。代码、样式和 Three.js 均已内联，无外部运行依赖。GitHub Pages 从 `main` 分支根目录发布；更新 `index.html` 即可更新公开课堂。

当前发布：2026-10-13 · equilibrium-v4。29 项平衡与稳定性检查、43 项浏览器交互检查通过。

## 模型与资料

本课是单位桥长单自由度的静力扭转教学模型。动画表示净力矩驱动趋势，不表示真实动力时间响应；超过局部 ±10° 工作窗的翻转画面标为线性发散外推。桥梁示意几何不作为工程设计或破坏预测。

规范公式和来源在页面中注明，链接至交通运输部公开的《公路桥梁抗风设计规范》JTG/T 3360-01—2018。课程不托管规范 PDF。
